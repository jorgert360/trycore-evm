# AI_PROCESS

## 1. Herramientas de IA utilizadas

### ChatGPT

Utilicé ChatGPT como apoyo durante el desarrollo de la prueba técnica para:

- organizar el plan de trabajo;
- resolver errores de configuración;
- analizar errores de compilación;
- orientar la integración entre NestJS, Prisma y PostgreSQL;
- apoyar la implementación del backend;
- revisar el flujo de Git y Gitflow.
